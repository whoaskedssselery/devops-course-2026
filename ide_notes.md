# VS Code vs Терминал для Git

## Удобно в VS Code:
1. Визуальный просмотр diff — сразу видно, что изменилось
2. Клик для staging/unstaging файлов вместо запоминания команд
3. История коммитов в графическом виде

## Удобнее в терминале:
1. Interactive rebase (git rebase -i) — в терминале это делать проще и понятнее
