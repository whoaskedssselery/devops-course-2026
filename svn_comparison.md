# Git vs SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
 - В Git ветка - это просто указатель (40-байтный файл с хэшем коммита), создаётся мгновенно, а в SVN ветка - это физическое копирование целой директории на сервере.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
 - Нет, в SVN коммит сразу пишется на единственный сервер, без сети это невозможно. В Git коммит делается локально (в свою полную копию репозитория), а на сервер уходит уже потом через push.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- Legacy-системы в госсекторе/банках, где уже вложены годы в инфраструктуру и миграция нецелесообразна
- Также иногда SVN проще для строгого пути-ориентированного контроля доступа или для очень больших бинарных файлов, где полная история Git становится неудобной.
